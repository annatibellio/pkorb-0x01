# ARCHIVE 001 // ACCESS NOTES

Você recebeu acesso a um arquivo recuperado. Ele não está completo — e não deveria estar.

## Como abrir
Dê duplo clique em `index.html`. É só isso. Não precisa instalar nada, não precisa de internet.

## O que você vai ver
Um painel de investigação e um terminal.

- **INVESTIGATION PANEL**: mostra seu progresso (quais fases você já resolveu), as evidências e os fragmentos decodificados que você já encontrou. Clicável/expansível no topo.
- **Área da missão**: descreve o que está em aberto na fase atual, e tem um campo `ANSWER>` para você responder quando achar a solução.
- **Terminal** (`$`): é onde você investiga de verdade. Digite `help` para ver as ferramentas disponíveis. É um sistema de arquivos fictício — use `ls`, `cat`, `file`, `grep`, `decode` e companhia para vasculhar o que sobrou do arquivo.

## Algumas dicas de uso (não de solução)
- Cada fase libera arquivos novos quando você acerta a resposta anterior.
- O botão **Hint** dá uma pista (só uma, por fase) se você travar.
- Seu progresso fica salvo automaticamente no seu navegador. Pode fechar e voltar depois.
- **Reset investigation** apaga tudo e começa do zero, se você quiser.
- Preste atenção em tudo. Nem tudo que parece pista é pista — e nem tudo que parece ruído é ruído.

Boa sorte. O coelho está observando.
